# Marshal Games

Небольшая коллекция браузерных игр. Без аккаунтов, рейтингов и сервера.

- **Погаси свет** — переключай клетки и соседей, пока всё поле не погаснет. Размеры 3×3, 4×4 и 5×5, подсказки и отмена хода.
- **Найди пару** — карточки на память. 6, 8 или 10 пар.
- **Пятнашки** — собери числа по порядку. Поля 3×3 и 4×4, отмена хода.
- **Рикошет** — аркада с платформой и мячом. Три уровня, три жизни, мышь, касание и стрелки. Пауза при уходе с вкладки.
- **Точный момент** — игра на реакцию. Двенадцать попаданий в движущуюся зону, три допустимых промаха, постепенное изменение скорости и направления.
- **Рывок** — раннер с двойным прыжком, растущей скоростью и генерируемыми препятствиями. Управление касанием или клавиатурой.

Сайт адаптирован для телефона и клавиатуры. Правила открываются кнопкой «?», по наведению или при фокусе с клавиатуры. Результат отображается поверх поля, оставляя выбор размера доступным. Подвал находится внизу коротких страниц и после содержимого на длинных.

Начатые партии сохраняются в `localStorage` этого браузера. Нетронутое или решённое поле при повторном входе заменяется новой раскладкой. В «Погаси свет» новая раскладка всегда отличается от предыдущей. При очистке данных браузера прогресс исчезнет. Новая игра не сбрасывает начатую партию без подтверждения.

## Разработка

Требуется Node.js 22+. Внешних npm-зависимостей нет.

```sh
npm run dev
npm test
npm run build
```

Предпросмотр: `http://127.0.0.1:4173`. Готовый сайт находится в `dist/`. Содержимое `public/` также можно разместить на любом статическом хостинге без сборки.

## GitHub Pages

Workflow `.github/workflows/pages.yml` проверяет игровую логику, собирает сайт и публикует изменения из `main`. В Settings → Pages источником должен быть выбран **GitHub Actions**. В pull request запускаются только тесты и сборка.

Все ссылки на ресурсы относительные, навигация использует hash-маршруты. Сайт работает и по адресу `https://kurwachka1.github.io/MarshalGames/`, и в корне собственного домена.

Подключение `play.marshalrf.ru` описано в [docs/DOMAIN.md](docs/DOMAIN.md).

## Как добавить игру

1. Создать модуль в `public/js/games/` по примеру существующих. Игровая логика отделена от DOM.
2. Экспортировать описание, уровни сложности, создание и проверку состояния, ход, проверку победы и счётчики.
3. Добавить игру в массив `games` и её отображение в `public/js/app.js`, стили в `public/assets/styles.css`.
4. Добавить проверку правил и генерируемых раскладок в `tests/`.
